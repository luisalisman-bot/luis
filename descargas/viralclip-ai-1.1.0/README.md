# ViralClip AI para Windows

[Descargar instalador .exe](https://raw.githubusercontent.com/luisalisman-bot/luis/viralclip-windows-v1.1.0/descargas/viralclip-ai-1.1.0/ViralClip-AI-Setup.exe)

[Descargar paquete completo ZIP](https://raw.githubusercontent.com/luisalisman-bot/luis/viralclip-windows-v1.1.0/descargas/viralclip-ai-1.1.0/ViralClip-AI-Entrega-Windows.zip)

Windows 10/11 de 64 bits. Ejecuta el instalador y mantén la conexión a Internet mientras descarga Node.js y dependencias y compila la aplicación. Después abre el acceso directo ViralClip AI. El ZIP incluye el instalador, código fuente, guía y resultados de las pruebas.

El instalador no está firmado y todavía no se ha ejecutado en Windows. Las pruebas de compilación, integración y navegador se hicieron en Linux. No se verificaron en esta sesión la transcripción Whisper ni descargas reales de YouTube. No se garantiza ausencia de fallos ni se otorgan derechos sobre contenido ajeno. La aplicación no añade marca de agua por defecto.

Consulta COMPARACION_Y_PRUEBAS.md para el alcance y las limitaciones. Solo usa contenido propio o autorizado.
